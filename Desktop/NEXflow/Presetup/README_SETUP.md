# คู่มือติดตั้ง NEXflow — สำหรับร้านค้า

> ทำขั้นตอน 1-3 ที่ **เครื่อง Server** (เครื่องหลักของร้าน) เพียงครั้งเดียว

---

## ขั้นตอนที่ 1 — ติดตั้งโปรแกรมที่จำเป็น

**ต้องต่อ Internet ก่อน**

ดับเบิลคลิก: `1_install_software.bat`  
→ ระบบจะขอสิทธิ์ Admin → กด **Yes**  
→ รอจนขึ้น "ติดตั้งโปรแกรมทั้งหมดเสร็จสิ้น!"

> ติดตั้ง Node.js + Git for Windows + PostgreSQL 18 อัตโนมัติ

---

## ขั้นตอนที่ 2 — ตั้งค่าฐานข้อมูล

ดับเบิลคลิก: `2_setup_database.bat`  
→ รอจนขึ้น "ตั้งค่าฐานข้อมูลเรียบร้อย!"

> สร้างฐานข้อมูลและ user admin (รหัสผ่าน: 1234)

---

## ขั้นตอนที่ 3 — เปิด Port สำหรับเครื่องอื่น

ดับเบิลคลิก: `3_open_firewall.bat`  
→ จดหมายเลข IP ที่แสดงขึ้นมา เช่น `192.168.1.5`

> เปิดให้เครื่องอื่นในร้านเข้าใช้ได้ผ่าน LAN

---

## เปิดใช้งานทุกวัน

**เครื่อง Server:** ดับเบิลคลิก `start-desktop.bat` ที่โฟลเดอร์ NEXflow  
→ หน้าต่าง NEXflow จะเปิดขึ้นอัตโนมัติ  
→ จะแสดง URL สำหรับเครื่องอื่น

**เครื่องอื่นในร้าน:** เปิด Chrome หรือ Edge พิมพ์:
```
http://192.168.X.X:3000
```
(ใช้ IP ที่ได้จากขั้นตอนที่ 3)

> ลืม IP? รัน `4_show_server_ip.bat` บนเครื่อง Server

---

## ปัญหาที่พบบ่อย

**เครื่องอื่นเข้าไม่ได้**
- ตรวจสอบว่า `start-desktop.bat` เปิดอยู่บนเครื่อง Server
- รัน `3_open_firewall.bat` อีกครั้ง
- ตรวจสอบให้แน่ใจว่าทุกเครื่องอยู่ใน WiFi/LAN เดียวกัน

**เข้าระบบไม่ได้**
- Username: `admin` / Password: `1234`
- ถ้ายังไม่ได้: รัน `2_setup_database.bat` อีกครั้ง

**API Error / ไม่โหลดข้อมูล**
- ปิด NEXflow แล้วเปิด `start-desktop.bat` ใหม่
- ตรวจสอบว่า PostgreSQL service ทำงานอยู่
